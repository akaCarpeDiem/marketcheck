What this page is

Market Check is a checker: a free public board of live market prices and headlines. It does not execute trades, hold funds, open accounts for trading, or publish price predictions as fact. Nothing here is investment advice.

Quote sources

  • Crypto (top list, many bubbles / trending) — CoinGecko public markets API (and related public crypto endpoints where noted in-module).
  • US equities, ETFs, indexes, commodities, metals, oil — Yahoo Finance quote / chart endpoints, proxied through Market Check’s /api/markets and /api/chart Cloudflare Functions (no Yahoo API key).
  • Search / single-symbol check — same Yahoo proxy for typed tickers (e.g. AAPL, BTC-USD); catalog search via /api/assets.

Upstream providers have their own terms, rate limits, and delays. Figures can be incomplete, stale, or wrong relative to any broker or exchange.

Headlines

Aggregated server-side from public RSS / Atom feeds (no publisher affiliation). Categories include traditional finance, crypto, politics, housing, technology, AI, and others shown as tabs on the dashboard. Typical outlet families: major wire / newspaper business & tech feeds, selected crypto outlets, and some YouTube channel Atom feeds for video mix. We never invent articles; the UI notes when a category is thin.

Refresh intervals (typical)

  • Main quotes (hero, crypto table, stocks/ETFs, indexes): about 45 seconds (configurable at build via VITE_REFRESH_MS).
  • Sparklines: about 15 minutes.
  • Bubble map: about 90 seconds.
  • Trending pumps/dumps: about 2 minutes.
  • Headlines: about 6 minutes (server cache often 5–10 minutes).

Stale data & errors

If a feed fails, the UI keeps the last good value only when it is also marked stale (badge or module note). Otherwise you should see an explicit error / unavailable state — not a blank card pretending to be live. Module footers show source name and as-of time where applicable.

Market hours strip

The NYSE / Nasdaq open–closed strip is an estimate from America/New_York wall time (regular session Mon–Fri 09:30–16:00 ET) plus a thin holiday list. It is not an official exchange calendar. Early closes and unlisted holidays will be wrong — treat the label as a hint only.

Watchlist

The watchlist is stored in your browser’s localStorage only. There is no cloud sync for watchlists on the public checker. Clearing site data clears the list.

Shareable symbol links

Searching a symbol updates a shareable query URL such as https://marketcheck.money/?q=AAPL. Paths like /quote/AAPL redirect to the same query form. These load one symbol from the existing Yahoo (and catalog) APIs — we do not prerender thousands of static quote pages.
